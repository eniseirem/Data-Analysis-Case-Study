# Web app

Streamlit app. Must run directly from this folder on another computer with no changes — relative paths only, and it must read only the final dataset from `../data/processed/case_study/`.

Single-file app: `SoSe26_Case_Study_App_Group_19.py`. Navigation between Home/Map/Charts/Table
is a sidebar radio, not Streamlit's folder-based multipage feature - kept to one file to match
the submission spec literally.
Assets: `assets/logo/`, `assets/fonts/` (Source Sans Pro).
